# 自生长个人知识库

## 摘要

「自生长个人知识库」是用 [[llm-wiki|LLM Wiki]] 方法 + [[obsidian|Obsidian]] + Agent（[[workbuddy|WorkBuddy]] / [[codex|Codex]]）构建的一套能持续增量演化的个人知识系统。核心是把知识管理从「一次性手工整理」变成「持续运行的维护机制」：资料进入 Raw 后，Agent 按 Schema 规则完成归档、关联和更新，零散资料逐步长成属于自己的知识网络。

## 核心内容

### 为什么「自生长」

自生长来自知识结构的**持续增量更新**：每当新资料进入 Raw 层，Agent 按 Schema 检索现有 Wiki，补充已有页面、创建新节点、建立双链，并记录来源与观点冲突。每次处理都留下可复用的结构化结果，知识库随输入不断演化。

### 分工闭环

- [[obsidian|Obsidian]]：稳定的本地载体 + 可视化界面。
- [[workbuddy|WorkBuddy]] / [[codex|Codex]]：理解、判断与编排能力。
- [[wesight|WeSight]]：把入库、更新、查询进一步整合进日常笔记流程。
- 人：输入高价值资料 + 完成关键判断；Agent：承担重复维护。数据、规则与执行形成闭环。

### 三种搭建方法（难度由高到低）

1. **直接搭建法**：靠提示词 + `AGENTS.md` 手工搭，最灵活但门槛高，需持续调整 Schema。
2. **[[claude-obsidian]] 插件**：开源项目封装 ingest / retrieve 等 Skill，降低门槛，但操作仍在 WorkBuddy / Codex 中，缺可视化反馈。
3. **[[wesight|WeSight]] 知识大脑**：整合进 Obsidian 内部，人机协作闭环最顺滑（当前会员内测）。

### 资料搜集渠道

- 手机：ima 或其他剪藏工具，或 WorkBuddy 小程序。
- 电脑：Obsidian Web Clipper 浏览器插件一键剪藏。
- 其他散落来源（如飞书文档）：借 Agent 快速收藏进知识库。

### 关键认知

- 自生长 ≠ 完全自动化：哪些资料值得保留、规则如何设定、关键结论能否成立，仍需人的判断；AI 更适合承担重复、耗时且结构化的维护工作。
- 起步不必求完美：先建好三层目录，放入一篇真实资料，让 Agent 完成第一次增量更新，再按实际使用调整 Schema。
