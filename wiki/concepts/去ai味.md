# 去 AI 味

## 摘要

「去 AI 味」是让 AI 生成的文字摆脱"一眼假"套路的方法论。AI 味不是个别词的问题，而是大量模式同时出现——开头正确的废话、整齐到反常的结构、金句式结尾、空泛总结、缺乏个人温度。真正的去 AI 味，目标不是骗过 AI 检测器，而是让文字更自然、更具体、更有作者自己的信息密度。

## 核心内容

### 什么是 AI 味

典型表现：

- **正确的废话开头**："随着人工智能技术的快速发展……"——没错，但没信息。
- **结构味**（最顽固）："首先…其次…最后…""不仅…而且…""从技术/商业/用户三个层面来看…"——真人写东西通常没这么整齐。
- **金句式结尾**："已经不是选择题，而是必答题"。
- **空泛总结** + **过度排比** + **名词化表达** + **宣传稿腔/公文腔**。

关键洞察：一个真人偶尔写一句"总而言之"不会变 AI；真正的 AI 感来自**大量模式同时出现**。

### 去 AI 味的正确姿势

- **不是换词，是重构**：同义词替换（"详细分析"→"深入分析"）AI 味一点没少；要改句子、段落、信息顺序。
- **不迷信检测率**：AI Detector 不可靠（真人被误判、AI 改写后逃过），只能当辅助，不能当裁判。
- **禁止编造经历**：为了"人味"编造"我折腾了三小时"是造假，不是 Humanize。没有真实经历，宁愿不写。
- **核心是增加作者信息密度**：真正的人味来自 AI 不知道的东西——用了几天、哪里失败、花了多少钱、客户抱怨什么、为什么改变观点。

### 递进层次

去 AI 味可按目的分四层（详见 [[ai写作去味]]）：

1. 去掉最明显的 AI 腔（[[stop-slop]] / [[humanizer-zh]] / qu-ai-wei）
2. 把文字改成正常人说的话（[[shuorenhua]]）
3. 建立自己的文风（[[writing-style-skill]] / WRITING.md / [[个人写作风格库]]）
4. 建立自己的思维与判断系统（[[nuwa-skill]]）

> 第 3 层存在两条实现路径：Skill 形态（手动收集样本）与平台功能形态（[[chatgpt]] Writing Style 自动摄取）。分歧与取舍见 [[ai写作去味]] 的「三条技术路线」。

### 特征的实证检验（新增，2026-09-15）

[[去ai味语料实证研究]] 用 283 万字平行语料对 26 项候选特征做了频率比检验，**只有 11 项通过**，并**证否了若干流行认知**（**✅ 已核实 2026-09-15：[[lieflat-less-ai-tone]] 仓库 README 与 SKILL.md 均已查证，数据与下表一致**）：

| 结论 | 数据 |
| --- | --- |
| **"AI 爱设问"是错的** | 人类设问频率是 AI 的 **17 倍**（1.83 vs 0.10 每千字）；按"减少设问"改只会离人类更远 |
| **"AI 比喻多"是错的** | AI 比喻**总数反而低于人类**（人类是 AI 的 **2.4 倍**，独立成段者 **8 倍**）；问题在**不够贴切**，细分后只有**拟人化喻体**显著（7.3×，带"永不/智慧的"修饰时 **12.6×**） |
| **"AI 句子长度太整齐"未通过** | 最初显示 51 倍，实为切句 bug（Markdown 表格被当成一整句，出现 19,335 字的"段落"）；修正后 0.87，**无差异** |
| **数据密度方向相反** | AI 数字密度只有人类的 **0.35×**——翔实的数据支撑能让文章**不那么** AI 味 |
| **显著项集中在篇章结构层** | 冒号空转句 9.4× ＞ 拟人化喻体 7.3× ＞ 段首零回指评论 4.4× ＞ 提示语冒号 3.8×；**词汇和标点上反倒不明显** |
| **没有统一文风** | 同一特征模型间最大差 **40 倍**（破折号：DeepSeek 5.16 vs GPT 0.11 每千字） |

**补充关键细节（已核实，来自 README 原文）**：

- **段首衔接词的总体密度两侧无差异**（AI 14.4% vs 人类 15.1%）——问题不在"不用衔接词"，而在**评论句省掉了回指成分**。补一个"这"字即可。
- **比喻的差异在喻体选择**：AI 偏好**理想化的职业人格**（"像一位智慧的导师"），人类多取**具体个人**（"像一个老师傅"）。前者承担**抒情**功能，后者承担**说明**功能。
- **以下都是人类同样在用的正常写法，明确不是 AI 味、不应修改**：被动句、名词化、长句本身、句内同构排比、正文"首先…其次"、比喻本身、问句与设问。

详细方法与边界见 [[ai味特征实证]]、[[lieflat-less-ai-tone]]。

### ⚠️ 一个必须记录的警示

[[lieflat-less-ai-tone]] 作者**公开了自己的六次测量失误**，其中**四项若未修正将直接进入规则集，两项方向相反**——"据以改写将使文本更偏离人类写作特征"。

> 这提示：**本节的特征清单本身也受测量方法限制**。作者自陈的根本局限是——"若'AI 味'的主要成分位于**语义层**，本研究的方法在**原理上无法触及**"。
>
> 换言之：**不要把这 11 项当成"AI 味的完整定义"，它只是"能被正则算子可靠测量且通过检验的那一部分"。**
