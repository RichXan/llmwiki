# 概念：长期记忆

## 摘要

**长期记忆** 指让 Agent 在会话结束之后仍能沉淀并复用信息的机制，与仅存活于当前 [[上下文窗口]] 的短期记忆相对。来源的核心论断是：**[[上下文管理]] 不是真正的记忆**——它只是在当前窗口里"拆东墙补西墙"，关掉终端或 `/clear` 后一切归零；真正让 AI 变得顺手，靠的是跨越会话的长期记忆。来源见 [[agent工程解析-上下文管理]]。

## 核心内容

### 为什么上下文管理不算记忆

- 上下文治理手段（压缩、折叠、落盘）都在**不可逆地丢失细节**，纯粹用"丢细节"换生存时间。
- 会话一关或 `/clear`，建立起来的默契与关键决策瞬间消失，下次要像"带新实习生"一样重新教一遍。
- 它记不住你的偏好、任务的历史、以及"你是谁"。

### Claude Code 的本地记忆（来源披露的形态）

- **存储路径**：`~/.claude/projects/.../memory/`。
- **记忆类型**：`user`（用户角色/偏好/知识背景）、`feedback`（用户纠正/确认的工作方式）、`project`（项目进展/目标/截止日期）、`reference`（外部系统资源指针）。
- **不该保存**：代码模式、git 历史、调试方案。
- **存储格式**：frontmatter + `MEMORY.md` 索引。
- **读取时机**：相关时 / 用户要求时。
- **验证规则**：记忆可能过期，需与当前状态核对。
- **物理限制**：读取时超过 200 行或 25KB 会被硬截断（见 [[上下文管理]]）。
