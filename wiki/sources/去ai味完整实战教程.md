# 来源摘要：去AI味完整实战教程

## 摘要

本文作者（X：[@ai_Goge](https://x.com/ai_Goge)）系统拆解了「去 AI 味」这件事：先厘清什么叫 AI 味（套路化表达、空泛总结、过度排比、结构味），再澄清「别把 AI 检测率当终极标准」，然后按「检测 → 清理套路 → 中文重写 → 说人话 → 建立文风 → 提取思维」的递进，梳理了 GitHub 上十几个相关 Skill/项目的分类与组合方式，最后给出一套从初稿到人工终审的完整工作流。

## 核心内容

1. **什么是 AI 味**：不是几个词（"值得注意的是/综上所述"），而是大量模式同时出现——开头正确的废话、结构永远整齐（首先/其次/最后）、金句式结尾。最顽固的是**结构味**（不仅…而且… + 三并列 + 因此 + 不是…而是…）。

2. **关键误区**：AI 检测率（AI Detector）不是终极标准，检测器本身不可靠；目标是"写得更自然"，不是"骗过检测器"。

3. **Skill 四层选择法**：第一层去明显 AI 腔（stop-slop-zh / Humanizer-zh / qu-ai-wei）→ 第二层说人话（shuorenhua）→ 第三层建立文风（writing-style-skill / WRITING.md）→ 第四层建立思维系统（nuwa-skill）。

4. **完整工作流（6 步）**：AI 做资料与第一稿 → AI 腔检查 → 中文重写 → 加入只有你知道的信息 → writing-style-skill 统一文风 → 从修改中持续学习。

5. **发布前 7 项自检**：开头能否删一段 / 有无模板化排比 / 有无空话 / 有无编造经历 / 有无作者自己的判断 / 有无具体事实数据 / 读出来是否别扭。

6. **核心结论**：去 AI 味的终点不是骗过 AI Detector，而是**增加作者信息密度**——经历、判断、数据、失败、观察，这些无法用一句 Prompt 批量复制。
