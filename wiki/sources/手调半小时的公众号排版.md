# 来源摘要：手调半小时的公众号排版，这篇25秒排完了

## 摘要

本文作者 [[davinci-seven|达芬七]] 分享了自己做的公众号排版流水线 [[wechat-article-pipeline]]：把定稿 Markdown 和配图放进文件夹，跑一条命令，25 秒产出可直接粘贴到公众号后台的排版（实测 3864 字、5 张图）。文章既介绍工具用法，也复盘了作者踩过的三个"表面成功、实则失败"的工程坑，并明确交代底层能力来自开源社区的三个项目（[[gzh-design]]、xiaowan-wechat-layout、md2wechat）。

## 核心内容

1. **痛点**：Markdown 复制进公众号后台后格式全乱（标题变井号、粗体星号外露、图片丢失），手调排版半小时起步。

2. **工具**：`wechat-article-pipeline`（GitHub: davinci-seven/wechat-article-pipeline，MIT），六套主题（橄榄手记/摸鱼绿/红白/石墨极简/留白禅意/摸鱼票据）。

3. **四样产出**：预览页、发布稳定版（图片内嵌 HTML，不依赖本机路径）、390px 手机长截图、检查报告（原稿哈希、HTML 合规、隐私扫描、图片证据表）。

4. **三条底线**：不改原稿、不替你发布、图片少一张就报错（SHA256 前后校验，对不上中止）。

5. **三个踩坑故事**（工程严谨性）：
   - 长截图"假装成功"（文档写了却没实现）→ 重接 Playwright 真实截图。
   - 隐私检查"0 ERROR"骗了自己（PowerShell 5.1 Tee-Object 默认 UTF-16LE，脱敏脚本按 UTF-8 读成乱码）→ 重写为显式 UTF-8 + BOM 识别。
   - 外部审核发现渲染器遇不支持语法不报错 → 补齐语法、命中即停并报原因。

6. **底层依赖（作者声明非己所写）**：[[gzh-design]]（公众号编辑器兼容）、xiaowan-wechat-layout（手机端结构检查/图片证据/排版 QA）、md2wechat（素材上传与草稿创建，商业使用需看 LICENSE）。
