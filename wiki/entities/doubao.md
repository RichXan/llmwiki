# 实体：豆包（Doubao）

## 摘要

**豆包（Doubao）** 是**字节跳动**推出的 AI 助手产品。在本库的 AI 自媒体内容生产线中，它同时出现在**写作**与**视频生成**两个环节：[[10个skill搭建公众号写作系统]] 将其列为 AI 写作与配图工具之一；[[爆款复刻-古风武侠英语剧]] 则用它完成**全流程短视频生产**（智能体写脚本 + 视频模型出片）。

> ⚠️ **本页未做网络检索核实**，信息来自本库两份来源文章的使用场景描述，**不做产品规格陈述**。

## 核心内容

### 本库中的使用场景

| 场景 | 来源 | 用法 |
| --- | --- | --- |
| **工作任务模式建智能体** | [[爆款复刻-古风武侠英语剧]] | 网页版或 App → 切到**【工作任务】**模式 → 粘贴提示词 → 一键创建专属智能体（用于**批量产出规范化短视频脚本**，并焊死"禁止造词"等红线） |
| **视频生成** | [[爆款复刻-古风武侠英语剧]] | 新开对话 → 【视频生成】→ 模型选 **Seedance 2.0 Fast** → 比例选 **16:9 横屏** → 粘贴提示词 |
| **AI 写作 / 配图** | [[10个skill搭建公众号写作系统]] | 作为推荐工具清单中的一项（与 [[codex]]、Claude、NotebookLM 并列） |

### 视频模型：Seedance 2.0 Fast

- 命名关系：**Seedance** 是字节跳动的视频生成模型系列，**豆包是其面向用户的产品入口**；[[fal]] 页记录 Seedance 2.0（2026-02 发布，Fast/Pro 双档）亦可经 fal / ByteDance ModelArk 调用。
- 来源称豆包生成结果"**画面色彩统一，连打斗和粤语武侠风纯音乐都一次性渲染到位，完全不用二次调色和到处找 BGM**"（**作者主观评价**）。
- 来源称"每天有 5 条免费额度"（**未核实**）。

### 与本库"视频生成"生态的关系

| | 说明 |
| --- | --- |
| [[fal]] | 生成式媒体模型**聚合 API 平台**（985 endpoints），包含 Seedance 2.0。面向 **Agent/开发者** |
| **豆包** | 字节**官方产品入口**，面向**普通用户**，同一模型的消费级界面 |
| [[replicate]] | 开源模型托管 / 推理 API 平台，面向开发者 |

→ 三者不是竞品关系，而是**同一批模型的不同接入层**。[[agent自动化获客完整指南]] 中 agent 通过 replicate / fal 生成素材；[[爆款复刻-古风武侠英语剧]] 中则是人在豆包网页端手动操作——**这正是"全自动 Agent 工作流"与"人工 SOP 工作流"的分野**。
