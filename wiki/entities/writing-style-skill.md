# writing-style-skill

## 摘要

writing-style-skill 是让 AI「写得像我」的 [[去ai味|去 AI 味]] 进阶 Skill——前一类工具解决"怎么让文章不像 AI"，它开始解决"怎么让 AI 写得像我"。GitHub 上存在多个同名/类似思路的项目。

## 核心内容

### 两种做法

1. **基于已有内容提炼文风**（https://github.com/lout33/writing-style-skill）：
   - 收集 10–20 封自己写的邮件、文章、X 帖子、微信聊天、公众号。
   - 分析：习惯长句还是短句、怎么开头、会不会寒暄、怎么表达不同意见、常用词、哪些词从不用。
   - 把这些规律保存成自己的 Style 文件，AI 生成后再按 Style 重写。

2. **从修改中自动学习**（https://github.com/jzOcb/writing-style-skill）：
   - 闭环：AI 写第一版 → 你人工修改 → 系统比较两版差异 → 提取修改规律 → 更新 Skill → 下次写得更像你。
   - 例：AI 总写"不是…而是…"，你每次改成直接下判断，系统就会减少这种句式。
   - 价值：很多人说不清自己的文风，但**修改记录不会骗人**。

### 相关思路：WRITING.md

- 直接维护一份自己的 `WRITING.md` 写作说明书：喜欢怎么写、不喜欢怎么写、什么表达禁止出现、教程/产品/观点文章分别怎么写、何时举例、何时删总结。
- 相当于"你的 AI 写作说明书"，AI 写作前先读它。

### 在工作流中的位置

属于「第三层：建立自己的文风」，目标是"不要只像真人，要开始像你"。

### 与 ChatGPT Writing Style 的关系（同源异流）

本 Skill 与 [[个人写作风格库]]（[[chatgpt]] 的 Writing Style + 语料库）都以"从真实文本提炼个人文风"为核心，区别在载体：前者是 **Skill 形态、需手动收集样本**，后者是 **平台原生功能、自动摄取并持续更新**。可以说本 Skill 恰好落在 [[ai写作去味]] 「两条技术路线」的交集上——既属于 Skill 生态，又是样本派思路。
