# 实体：Whop（含 whop ads）

## 摘要

**Whop** 是一个数字产品/电商类平台，在本库中出自 [[agent自动化获客完整指南|Chris Everest 获客指南]]：其广告产品 **whop ads** 允许卖家从 whop 后台直接在 Facebook / Instagram（Meta）投放广告，无需自建 Meta 广告账户。在指南的 Pipeline 一中，whop 承担**销售页托管、支付归因与广告投放**三个环节。

## 核心内容

### 来源中的描述

| 维度 | 描述 |
| --- | --- |
| **广告机制** | whop ads 跑在 whop 自己的 Meta 代理账号上（作者称处于"Meta 最高层级"），投 Facebook 与 Instagram；素材为竖版视频与静图，用 Meta 的三种尺寸比例 |
| **账户优势** | 作者称：竞价里优先、规模化后千次展示成本更低、被拒次数远少于新账号（作者说法，待核实） |
| **归因** | pixel 已内置于 whop 页面，用**真实支付数据**归因——转化被计入即"真的有人付了钱"；转化回传给 Meta 优化系统 |
| **资金** | 投放资金当天可从 whop 的待结算余额支出（"广告带来买家，买家养广告"）；使用 whop ads 本身免费，只付投放花费 |
| **线索回收** | whop 告知谁访问过页面、谁到过结账步骤，agent 对"点了没买"的人跟进 |
| **内容审核** | 拒收带承诺的素材：不能编收入数字、不能用假证言、不能暗示买家会得到某种结果；一条被拒会拖累整个广告组 |

### 在本库中的角色

- 代表"**数字产品销售 + 广告投放一体化**"的平台模式：把支付、归因、投放三件事打包，降低个人卖家的投放门槛。
- 其真实支付数据归因与"每单成本 vs 产品价格"的评估口径，是 [[agent自动化获客]] 主题中少数可直接量化的指标。
