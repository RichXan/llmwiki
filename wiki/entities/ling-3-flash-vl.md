# 实体：Ling-3.0-flash-VL

## 摘要

**Ling-3.0-flash-VL** 是**蚂蚁 inclusionAI** 开源的多模态（视觉语言）模型，在本库中作为 [[视觉自愈循环]] 的实操模型出现：作者用它做"截图复刻页面 → 渲染截图 → 逐像素比对 → 自诊断自修改"的闭环（见 [[ai改ui翻车]]）。

## 核心内容

### 基本信息

- **开发方**：inclusionAI（蚂蚁）
- **形态**：开源多模态模型（视觉理解 + Visual Agent）
- **公开参数（来源转引）**：总参数 **124B**，每次推理激活 **5.5B**
- **实测表现（来源）**：单次整页 HTML 生成约 **7 秒**——作者强调这只是其当时接口与设置下的调用记录，未做横向对比，也不应用激活参数推导速度与成本

### 获取途径（来源列出）

- Hugging Face：`inclusionAI/Ling-3.0-flash-VL`
- Ling studio：chat.ant-ling.com
- 蚂蚁数科 MaaS（国内站）
- OpenRouter（`:free` 版本）
- 来源称**开源且限免 2 周**

### 在本库中的角色

- 与 [[claude-code]]、[[codex]] 等"编码 Agent"不同，它在本库中代表**具备视觉理解能力的模型**在 UI 复刻场景的用法。
- 其价值不只在"生成第一版"（Screenshot-to-Code），更在**能看懂渲染结果并把问题落到具体 CSS**（见 [[视觉自愈循环]]）。
