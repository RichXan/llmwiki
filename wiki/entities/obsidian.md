# Obsidian

## 摘要

Obsidian 是一款本地化、数据自主的 Markdown 笔记软件。在 [[自生长个人知识库]] 这套系统中，它承担**存储底座、人机操作界面、知识观察窗口**三种角色：保存内容、连接与呈现结果，而 [[workbuddy|WorkBuddy]] / [[codex|Codex]] 负责执行。

## 核心内容

### 为什么选 Obsidian（而非 Notion / Ima / NotebookLM）

- **本地化与数据自主**：一个 Vault 就是电脑上的普通文件夹，笔记以 Markdown 纯文本保存，不依赖平台页面数据库；工具可以换，知识不用跟着搬家。
- **适合 Agent 工作**：Agent 可直接读取目录、创建页面、修改链接、维护索引，每次变化能定位到具体文件，还能通过 Git 留痕。
- **双链与图谱**：双链、反向链接、知识图谱把概念/人物/工具/主题连接起来，帮助发现核心节点、孤立页面和新的关联。
- **插件生态**：从模板、查询、版本管理到发布与可视化均可按需扩展。

### 在系统中的角色

- 存储底座：Markdown 文件长期保存。
- 人机界面：人阅读、浏览知识节点。
- 知识观察窗口：通过图谱观察知识结构变化。
