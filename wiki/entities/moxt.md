# 实体：Moxt

## 摘要

**Moxt**（moxt.ai）是一个**"组建 AI 团队来承担长程复杂工作"的平台**，由 [[lieflat-less-ai-tone]] 作者在文中提及，并在该仓库 README 的「关于 Moxt」一节中给出了**官方定位说明**。它是 [[去ai味语料实证研究]] 的**制作平台**，也是该 Skill 的**推荐运行环境**（MoxtHub）。

> ✅ **已核实（2026-09-15 GitHub 仓库 README）**：Moxt = **moxt.ai**，官方自述"组建 AI 团队来承担长程复杂工作的平台"，含四个组成部分（见下）。
>
> ⚠️ **其官方站点 `moxt.ai` 本批未直接打开**，产品细节来自 Skill 仓库 README 的转述。

### 「MoxtHub」

Moxt 内的 Skill 分发入口（`moxt.ai/.../hub?type=skill&id=...`）。作者推荐用它运行 `lieflat-less-ai-tone`，因为该 Skill "依赖**长文本的反复读取与逐句改写**，工作空间的上下文能力正对应这一需求"。
