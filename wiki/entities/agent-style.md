# agent-style

## 摘要

agent-style 是一套面向**英文技术写作**的 AI Agent 写作规则（共 21 条），一部分来自经典英文写作原则，一部分来自对 LLM 常见问题的长期观察。适合技术文档、README、研究文章、设计文档、专业报告、API 文档，以及 Claude Code / Codex / Cursor / Copilot 等 Agent 环境。

## 核心内容

### 适用范围（重要）

- 项目自身明确说明：主要面向**英文技术写作**，并非为中文长文、小说或营销文案设计。
- 中文创作者可以学习它的规则思想，但不必原封不动照搬。

### 与去 AI 味的关系

- 它是"写作规范/风格规则"，不是通用的中文去 AI 味工具；与 [[去ai味|去 AI 味]] 工作流中的 stop-slop / humanizer 定位不同。
