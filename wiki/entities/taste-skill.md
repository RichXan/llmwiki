# 实体：taste-skill

## 摘要

**taste-skill** 是面向**前端 / UI 审美**的 Skill，目标是让 AI 生成的前端界面**去同质化**、更像有品味的设计而非模板化产出。需要特别区分：它**不是文章去味工具**——它出现在 [[ai写作去味]] 的 Skill 全景表中，正是作为"名字像、领域不同"的对照项。

## 核心内容

### 基本信息

- **仓库地址**：https://github.com/leonxlnx/taste-skill
- **定位**：前端 / UI 审美（AI 前端 UI 去同质化）
- **社区热度（来源转引）**：约 **21k stars**
- **领域边界**：**非文章去味**，属 UI 生成质量范畴

### 在本库中的角色

- 在 [[ai写作去味]] 主题中，作为"易与文章去味混淆"的对照项出现。
- 在 [[ai生成ui]] 主题中，代表 AI 生成 UI 的**审美维度**——与 [[视觉自愈循环]] 关心的"像不像目标图"（复刻准确度）形成互补。
